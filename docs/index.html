Install

x86_64 host with hardware virtualization (KVM / HVF / WHPX), Android SDK with Emulator 36+, zstd, 8 GB RAM and ~10 GB free disk. Apple Silicon Macs can't run x86_64 images.

Download the image

Grab InfinityX-4.1-UNOFFICIAL-emulator-x86_64-20261024.tar.zst from the latest release.

Run the installer (Linux / Intel macOS)

It checks the SHA‑256, extracts the image into your SDK and creates an AVD named InfinityX.

git clone https://github.com/Necta14/infinityx-emulator-x86_64-unofficial
cd infinityx-emulator-x86_64-unofficial
./scripts/install.sh ~/Downloads/InfinityX-4.1-UNOFFICIAL-emulator-x86_64-20261024.tar.zst

Start it

$ANDROID_SDK_ROOT/emulator/emulator -avd InfinityX

Windows (untested): extract with a Zstandard-capable tool into …\Sdk\system-images\android-37\infinityx\ and create the AVD files shown in install.sh.

Tips

Small things that save time.

Black screen / artifactsStart with -gpu host, or -gpu swiftshader_indirect as a fallback.
Start clean-wipe-data resets the AVD; -no-snapshot forces a cold boot.
FingerprintsExtended controls (…) → Fingerprint: enroll several fingers and touch the virtual sensor.
Root shelluserdebug build, so try adb root first.
No setup wizardNormal for a vanilla build. It boots straight into the launcher.
PerformanceGive the AVD 4 cores and 4 GB of RAM (the defaults the installer sets), and keep the image on an SSD.

Not included / won't work

  • Official signing keys and OTA
  • Running on real phones (emulator only!)

FAQ

Is this official?No. It is an unofficial community build. Please don't ask the Infinity X groups for support with it.
Can I flash it on my phone?No. It is built for the emulator's virtual hardware only.
Is it safe?Built from public sources with the patches published here. Verify the SHA‑256 and inspect the build notes. It is not signed with official keys.
Found a bug?Check it on a real device first. If it only happens here, open an issue in this repo.
Kernel source?See NOTICE.md (Android Common Kernel 6.12.58).
