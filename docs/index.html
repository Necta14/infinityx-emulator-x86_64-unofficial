Install

You need an x86_64 computer with hardware virtualization, the Android SDK with Emulator 36 or newer, and about 10 GB of free disk space. Apple Silicon Macs can't run x86_64 images.

  1. Download the image

    Get InfinityX-4.1-UNOFFICIAL-emulator-x86_64-20261024.tar.zst from the latest release.

  2. Run the installer

    It checks the SHA‑256, extracts the image into your SDK and creates an AVD called InfinityX.

    git clone https://github.com/Necta14/infinityx-emulator-x86_64-unofficial
cd infinityx-emulator-x86_64-unofficial
./scripts/install.sh ~/Downloads/InfinityX-4.1-UNOFFICIAL-emulator-x86_64-20261024.tar.zst

  3. Start the emulator

    $ANDROID_SDK_ROOT/emulator/emulator -avd InfinityX

  1. Enable virtualization

    Turn on Windows Hypervisor Platform (WHPX) or install the AEHD driver from the SDK Manager.

  2. Extract the image

    Use a tool that reads Zstandard archives, such as tar from Git Bash or WSL, PeaZip or 7‑Zip ZS. Extract into:

    %LOCALAPPDATA%\Android\Sdk\system-images\android-37\infinityx\

  3. Create the AVD files

    Copy the two files that install.sh writes into %USERPROFILE%\.android\avd\, then start emulator -avd InfinityX. These Windows steps haven't been tested yet.

Questions

Is this official?expand_more
No. It's an unofficial community build. The Infinity X team doesn't support it, so please don't report its issues in their groups.
Can I flash it on my phone?expand_more
No. It's built for the emulator's virtual hardware only and won't boot on a real device.
Is it safe to run?expand_more
It's built from public sources plus the patches published in the repository. Check the SHA‑256 before installing. It isn't signed with the official Infinity X keys.
I found a bug. Where do I report it?expand_more
Check it on a real device first. If it only happens in the emulator, open an issue in this repository.
Where is the kernel source?expand_more
The image uses the AOSP prebuilt emulator kernel, Android Common Kernel 6.12.58. NOTICE.md links the exact source.
